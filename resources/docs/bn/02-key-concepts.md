# ব্যবসার মূল শব্দগুলো

এই অধ্যায়টি একবার পড়ে নিন – নির্দেশিকার বাকি অংশে এই শব্দগুলোই ব্যবহার করা হয়েছে।

## প্রতিষ্ঠান

| শব্দ | অর্থ |
|---|---|
| **শাখা** | আপনার ব্যবসার একটি দোকান / আউটলেট। অর্ডার, পেমেন্ট, কিস্তি চুক্তি ও ইএমআই রেকর্ড কোনো একটি শাখার অধীনে থাকে। কর্মীরা উপরের বার থেকে শাখা বদলান। |
| **গুদাম** | যেখানে স্টক রাখা হয় (শোরুমের ফ্লোর, পেছনের স্টোর, গোডাউন)। স্টক গোনা হয় **প্রতিটি গুদাম অনুযায়ী**। যেকোনো শাখা যেকোনো গুদাম থেকে বিক্রি করতে পারে; POS সেশন খোলার সময় গুদাম বেছে নিতে হয়। |
| **ব্যবহারকারী** | যে কর্মী লগ ইন করেন। |
| **রোল** | কিছু অনুমতির একটি নামযুক্ত সেট, যেমন *ক্যাশিয়ার*, *ম্যানেজার*। একজন ব্যবহারকারীর এক বা একাধিক রোল থাকতে পারে। |
| **অনুমতি** | একটি নির্দিষ্ট কাজ করার অনুমতি, যেমন *Product Export* বা *Order Void*। |
| **Super Admin** | মালিকের রোল। এটি সব কাজ করতে পারে, ভবিষ্যতের আপডেটে যোগ হওয়া কাজসহ। |

## ক্যাটালগ

| শব্দ | অর্থ |
|---|---|
| **ক্যাটাগরি** | পণ্যের প্রধান ভাগ, যেমন *এয়ার কন্ডিশনার*, *রেফ্রিজারেটর*। ক্যাটাগরির একটি প্যারেন্ট থাকতে পারে (যেমন *এয়ার কন্ডিশনার*-এর অধীনে *ইনভার্টার এসি*)। **প্রতিটি পণ্যের একটি ক্যাটাগরি লাগবেই।** |
| **সাব-ক্যাটাগরি** | প্রতিটি ক্যাটাগরির অধীনে উপ-ভাগের একটি অতিরিক্ত তালিকা। এখন এটি শুধু রেফারেন্স তালিকা – পণ্যের সাথে এটি যুক্ত হয় না; পণ্যের স্তরবিন্যাসের জন্য প্যারেন্ট ক্যাটাগরি ব্যবহার করুন। |
| **ব্র্যান্ড** | প্রস্তুতকারক, যেমন *Samsung*, *Walton*। পণ্যে দেওয়া ঐচ্ছিক। |
| **ট্যাগ** | খোঁজা ও ভাগ করার জন্য ইচ্ছেমতো লেবেল, যেমন *ঈদ অফার*, *বিদ্যুৎ সাশ্রয়ী*। একটি পণ্যে অনেকগুলো ট্যাগ থাকতে পারে। |
| **সাধারণ পণ্য** | যে পণ্যের একটি দাম এবং প্রতি গুদামে একটি স্টক সংখ্যা, যেমন *Walton 1.5 Ton Inverter AC WSI-KRYSTALINE-18C*। |
| **ভ্যারিয়েশনসহ পণ্য** | যে পণ্য কয়েকটি সংস্করণে বিক্রি হয়, যেগুলো কোনো অ্যাট্রিবিউটে আলাদা, যেমন একটি ফ্যান *রং: সাদা / বাদামি* এবং *সাইজ: 48" / 56"*-এ। প্রতিটি সংস্করণের (**ভ্যারিয়েশন**) নিজস্ব SKU, দাম ও স্টক থাকে। |
| **অ্যাট্রিবিউট** | যে বৈশিষ্ট্য থেকে ভ্যারিয়েশন তৈরি হয়, যেমন *রং*, *সাইজ*, *ক্যাপাসিটি*। |
| **অ্যাট্রিবিউটের মান** | একটি অ্যাট্রিবিউটের একটি অপশন, যেমন *সাদা*, *56"*, *1.5 Ton*। |
| **SKU** | *Stock Keeping Unit* – কোনো পণ্য বা ভ্যারিয়েশনের জন্য আপনার নিজের ছোট ও অনন্য কোড, যেমন `WAL-AC-15T`। |
| **বারকোড** | বক্সে ছাপানো কোড (EAN/UPC)। POS-এ স্ক্যান করলে পণ্যটি যোগ হয়। |
| **বিক্রয় মূল্য** | স্বাভাবিক দাম। |
| **ছাড় মূল্য** | কম অফার দাম। এটি দেওয়া থাকলে POS এই দামেই বিক্রি করে। |
| **সতর্কতার পরিমাণ** | প্রতি গুদামে যে স্টক লেভেলে পণ্যটিকে "কম" ধরা হয়। |
| **একক / মূল একক** | মাপের নাম (যেমন *Quantity*-এর অধীনে *Piece*)। এখন শুধু রেফারেন্স হিসেবে আছে; POS পূর্ণ সংখ্যায় বিক্রি করে। |
| **কর** | করের হার (শতাংশ বা নির্দিষ্ট পরিমাণ)। পণ্যে দেওয়া যায়, কিন্তু POS-এ কর **এখনো হিসাব হয় না** – ইনভয়েসে কর ০ দেখায়। |
| **ওয়ারেন্টি টেমপ্লেট** | তৈরি করা ওয়ারেন্টির লেখা (যেমন *কম্প্রেসর: ১০ বছর, পার্টস: ১ বছর*), যা ক্যাশিয়ার POS-এ বেছে নিতে পারেন; এটি ইনভয়েসে ছাপা হয়। |

## স্টক

| শব্দ | অর্থ |
|---|---|
| **স্টক ইন** | কোনো গুদামে পরিমাণ যোগ করে (নতুন কেনা মাল, গ্রাহকের ফেরত)। |
| **স্টক আউট** | পরিমাণ বাদ দেয় (নষ্ট মাল, নিজের ব্যবহার, উপহার)। |
| **স্থানান্তর** | এক গুদাম থেকে অন্য গুদামে পরিমাণ সরায়। |
| **পরিমাণ নির্ধারণ (সমন্বয়)** | গুনে পাওয়া সংখ্যা দিয়ে পরিমাণটি বদলে দেয় (স্টক গণনা)। |
| **স্টক মুভমেন্ট** | উপরের প্রতিটি কাজের জন্য লেখা ইতিহাস রেকর্ড – কে, কখন, কেন এবং একটি রেফারেন্সসহ। |

## বিক্রি

| শব্দ | অর্থ |
|---|---|
| **POS** | *Point of sale* – কাউন্টারে বিক্রির স্ক্রিন। |
| **POS সেশন** | একজন ক্যাশিয়ারের শিফট। একটি শাখা, একটি **গুদাম** (এখান থেকেই স্টক কাটা হয়) ও ওপেনিং ক্যাশ দিয়ে খোলা হয় এবং দিনের শেষে বন্ধ করা হয়। সেশন চালু না থাকলে বিক্রি করা যায় না। |
| **সাধারণ ক্রেতা** | সংরক্ষিত গ্রাহক ছাড়া বিক্রি (ওয়াক-ইন)। |
| **খসড়া** | সংরক্ষণ করা, অসম্পূর্ণ বিক্রি ("হোল্ড")। এতে স্টক কমে না এবং কোনো ইনভয়েস নম্বর থাকে না। |
| **সম্পন্ন বিক্রি** | শেষ হওয়া বিক্রি: স্টক কমে এবং `POS-20261025143010-15`-এর মতো একটি ইনভয়েস নম্বর দেওয়া হয়। |
| **বাতিল** | সম্পন্ন বা খসড়া বিক্রি বাতিল করা (Void)। সম্পন্ন বিক্রির স্টক তার গুদামে ফিরে যায়। এটি আর ফেরানো যায় না। |
| **পরিশোধিত / আংশিক / অপরিশোধিত** | অর্ডারের পেমেন্টের অবস্থা, যা পেমেন্টগুলো থেকে হিসাব করা হয়। |
| **বাকি** | কোনো অর্ডারে গ্রাহকের কাছে এখনো যে টাকা পাওনা। পরে **বাকি পরিশোধ** দিয়ে আদায় করুন। |
| **স্প্লিট পেমেন্ট** | একটি অর্ডারের দাম কয়েকটি পদ্ধতিতে পরিশোধ, যেমন কিছু নগদ + কিছু বিকাশ। |
| **ফেরত** | গ্রাহক মোটের চেয়ে বেশি দিলে যে টাকা ফেরত দেওয়া হয় (চেঞ্জ)। |

## বাকিতে বিক্রি

| শব্দ | অর্থ |
|---|---|
| **কিস্তি (হায়ার পারচেজ)** | দোকানের নিজস্ব বাকি সুবিধা: গ্রাহক এখন একটি **ডাউন পেমেন্ট** দেন এবং বাকিটা নির্ধারিত কিস্তিতে দোকানকে পরিশোধ করেন। |
| **কিস্তি পরিকল্পনা** | সংরক্ষিত শর্তের সেট (কিস্তির সংখ্যা, কিস্তির ব্যবধান, সুদ, ফি), যা ক্যাশিয়ার POS-এ বেছে নিতে পারেন। |
| **চুক্তি** | একটি বিক্রির কিস্তি চুক্তি, `INS-261025-000123`-এর মতো নম্বরসহ এবং কিস্তির সূচিসহ। |
| **ডাউন পেমেন্ট** | বিক্রির সময় পরিশোধ করা টাকা। |
| **কিস্তিতে পরিশোধযোগ্য (Financed amount)** | বিক্রয় মূল্য + প্রসেসিং ফি − ডাউন পেমেন্ট। |
| **ফ্ল্যাট সুদ** | সুদ = কিস্তিতে পরিশোধযোগ্য টাকা × হার, একবারই, সব কিস্তিতে সমানভাবে ভাগ করা। |
| **হ্রাসমান ব্যালেন্স সুদ** | ব্যাংকের মতো বাকি থাকা টাকার উপর সুদ (বার্ষিক হার)। |
| **প্রসেসিং ফি** | একবারের একটি ফি, যা কিস্তিতে পরিশোধযোগ্য টাকার সাথে যোগ হয়। |
| **বিলম্ব ফি** | যে কিস্তি নির্ধারিত তারিখের পর **অতিরিক্ত সময়ের (grace days)** চেয়েও বেশি দিন অপরিশোধিত থাকে, তার উপর একবার ধার্য হয়। |
| **ব্যাংক ইএমআই** | গ্রাহক ব্যাংকের POS মেশিনে ক্রেডিট কার্ডে পরিশোধ করেন এবং ব্যাংক সেটিকে মাসিক কিস্তিতে রূপান্তর করে। দোকান পরে ব্যাংক থেকে টাকা পায় (**নিষ্পত্তি**)। |
| **মেয়াদ** | ব্যাংক ইএমআই-এর মাসের সংখ্যা; প্রতিটির একটি **গ্রাহক %** (বিলের সাথে যোগ হয়) এবং **ব্যাংক %** (নিষ্পত্তির সময় ব্যাংক কেটে রাখে) থাকে। |
